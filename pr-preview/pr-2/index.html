isomill

Installation media that explains itself. A Machine Definition becomes a thin official Fedora or Ubuntu installer ISO. Identity and disk stay in the install shield. Packages resolve at install time via dnf or apt.

Machine Definition

Network install: Fedora Everything netinst or Ubuntu Desktop. Intel / AMD 64-bit and ARM 64-bit. We are not an OS mirror. GNOME only in v1. No users, passwords, or partitioning here.
